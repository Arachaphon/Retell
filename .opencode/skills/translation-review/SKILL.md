# Translation Review

ใช้เมื่อต้องรีวิว/ประเมินคุณภาพงานแปล โดยเน้นว่าเนื้อหาควรอ่านลื่นไหล
เหมือนภาษาเป้าหมายเขียนขึ้นเอง ไม่ใช่ "แปลตรงตัว" จนแข็ง และต้องรักษา
โทนอารมณ์ สำนวน และบริบทวัฒนธรรมของต้นฉบับไว้

## เมื่อต้องใช้

- ตรวจสอบคุณภาพการแปลนิยาย/บทความที่ระบบเคยแปลไว้
- แก้ส่วนที่อ่านแล้วแข็ง ไม่เป็นธรรมชาติ ถอดความ/สำนวนผิด
- ให้คะแนนหรือรีวิวงานแปลแบบละเอียดว่าดีหรือยัง ตรงไหนควรปรับ
- เปรียบเทียบการแปลกับต้นฉบับเพื่อหาความหมายที่คลาดเคลื่อน

## มิติที่ต้องตรวจ (ให้ครบทุกข้อ)

### 1. โทนและระดับภาษา (Tone & Register)
- ต้นฉบับเป็นทางการ/กันเอง/เกรี้ยวกราด/อ่อนโยน/ประชด ระดับไหน แล้วภาษาที่แปล
  รักษาระดับนั้นไว้ไหม
- อย่าแปลทุกอย่างให้เรียบๆ เหมือนกัน ต้องรักษาความแตกต่างของตัวละคร
  (ตัวละครห้วนๆ กับตัวละครสุภาพ ไม่ควรออกเสียงเป็นสไตล์เดียวกัน)
- บทสนทนาควรฟังดูเป็นคำพูดจริง ไม่ใช่ภาษาเขียนแบบรายงาน

### 2. สำนวนและความเป็นธรรมชาติ (Idiom & Naturalness)
- ถ้าดูเหมือน "แปลตรงตัว" (literal) จนแข็ง ให้ทุบแล้วเขียนขึ้นใหม่เป็นวิธีที่
  คนไทยพูดจริง เช่น
  - "It's raining cats and dogs" → "ฝนตกหนักมาก" ไม่ใช่ "ฝนตกลูกแมวลูกหมา"
  - "He bit the bullet" → "เขากัดฟันทำ" ไม่ใช่ "เขากัดกระสุน"
- ระวัง collocation ที่ไม่เป็นธรรมชาติ อย่ากู้คำแปลคำต่อคำแล้วมาประกอบกัน
- คำ/สำนวนที่ไม่มีคำเทียบตรง ให้ถอดความหมายให้ได้ใจความ ไม่ใช่แปลคำๆ

### 3. บริบทวัฒนธรรม (Cultural Context)
- ตรวจว่า cultural reference ที่คนไทยไม่รู้จัก ควรปรับให้เข้ากับบริบท
  (localize) หรือเก็บไว้แล้วเพิ่มคำอธิบายสั้นๆ
- คำสุภาพ/สรรพนามบอกชนชั้นหรือความสัมพันธ์ (เช่น ภาษาญี่ปุ่น/เกาหลีที่แฝง
  ลำดับชั้น) ต้องถ่ายทอดผ่านระดับภาษาไทยให้ผู้ฟังรับรู้ความสัมพันธ์นั้น
- ชื่อเฉพาะ, หน่วยเงิน, หน่วยวัด พิจารณาว่าจะเก็บเดิม/แปลง/เพิ่มเชิงอรรถ
- อย่าเปลี่ยนความหมายเชิงวัฒนธรรมไปในทางที่ผิด เพราะทำให้เนื้อเพี้ยน

### 4. ความครบถ้วนของความหมาย (Fidelity)
- ไม่ตัด/เติมข้อมูลสำคัญจนความหมายเปลี่ยน
- ไม่นำความหมาย "โดยนัย" ของต้นฉบับมาแปลงเป็นความหมาย "ตรงตัว" เกินจำเป็น
- ตรวจว่าอารมณ์แฝง (ประชด เสียดสี เย้ยหยัน) สื่อออกมาครบ

### 5. ไวยากรณ์และความไหลลื่น (Flow & Grammar)
- ประโยคไทยไม่ควรยาวเป็นลูกโซ่ก๊อปโครงสร้างภาษาอังกฤษ/ต่างประเทศ
- ตัดคำฟุ่มเฟือย, จัดให้อ่านลื่น, เลิก comma splice ที่เลียนแบบต้นฉบับ
- เครื่องหมายวรรคตอน ต้องใช้อันที่เหมาะกับภาษาไทย

## วิธีรีวิวที่ควรทำ

1. อ่านทั้งต้นฉบับกับคำแปลคู่กัน แล้วหาจุดคลาดเคลื่อน
2. จัดลำดับปัญหาเป็น 3 ระดับ:
   - **Blocker** — แปลผิดความหมาย / หลุดบริบทวัฒนธรรม / ตัวละครผิดโทน
   - **Major** — อ่านแข็ง ไม่อิน สำนวนไม่เป็นธรรมชาติ แต่พอเข้าใจ
   - **Minor** — เลือกคำได้ดีกว่า / กลางๆ ปรับเพื่อความลื่น
3. ให้ข้อเสนอแนะแบบ "พรรณนา" ไม่ใช่แค่ให้คำแปลใหม่คำเดียว อธิบายว่า
   ทำไมต้นฉบับรู้สึกแบบนั้น แล้วเสนอตัวเลือก 2-3 แบบพร้อมเหตุผล
4. ถ้าได้งานแปลที่ดีแล้วบอกไปตรงๆ ว่า "ผ่าน" พร้อมจุดแข็ง ไม่ใช่จับผิดทุกอย่าง

## เกณฑ์ช่วยตัดสินใจ

| ระดับ | เกณฑ์ |
|-------|-------|
| ผ่าน (Pass) | ความหมายครบ โทนคง เดิมตรง เล่นสำนวนเป็นธรรมชาติ อ่านลื่น |
| ผ่านแบบระวัง (Pass w/ notes) | มี Minor/Major บางจุดแต่แก้ได้ง่าย |
| ต้องแก้ (Revise) | มี Blocker หรือความหมายคลาดเคลื่อนกับต้นฉบับชัดเจน |

## ตัวอย่างการชี้จุด

```
ต้นฉบับ: "He pounded the table, his patience with the committee exhausted."
แปลเดิม: "เขากระทืบโต๊ะ ความอดทนที่เขามีต่อคณะกรรมการหมดสิ้นลงอย่างสมบูรณ์"
รีวิว:
- Major: "pounded" คือทุบ/ตบ โต๊ะเสียงดังด้วยมือ ไม่ใช่ "กระทืบ" (เหยียบ/เดินกระทืบ).
- Major: ประโยคหลังภาษาหนังสือเกินไป ควรกระชับแบบพูดจริง เช่น
  "เขาทุบโต๊ะอย่างแรง เพราะหมดความอดทนกับคณะกรรมการแล้ว"
ตัวเลือก: 1) ... 2) ...
```

## Checklist เมื่อรีวิวเสร็จ

- [ ] ตรวจครบ Tone, Idiom, Culture, Fidelity, Flow แล้ว
- [ ] ระบุระดับปัญหา (Blocker/Major/Minor) ของแต่ละจุด
- [ ] เสนอทางเลือกพร้อมเหตุผล ไม่ใช่แค่คำตอบเดียว
- [ ] สรุปว่าผ่าน / ผ่านแบบระวัง / ต้องแก้
